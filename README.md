# 📊 SQL Employee Data Analysis 

📌 Project Overview

This project focuses on analyzing Employee data using SQL. The project was created to practice SQL concepts such as data retrieval, filtering, aggregation, grouping, joins, subqueries, and conditional statements.

The SQL queries are designed to explore employee information and answer different business-related questions from the dataset.

🎯 Project Objectives

The main objectives of this project are:

* Analyze employee information using SQL
* Retrieve specific employee records
* Calculate aggregate statistics
* Analyze employees by department
* Compare salaries and other employee attributes
* Practice SQL joins and subqueries
* Solve real-world SQL analysis questions

🛠️ Tools & Technologies

* MySQL
* SQL
  
📂 Dataset

The project uses an employee dataset containing information such as:

* Employee ID
* Employee Name
* Department
* Job Role
* Salary
* Age
* Gender
* Joining Date
* Location

## 🧹 Data Preparation

The following SQL operations were used to prepare and analyze the data:

* Creating database and tables
* Inserting records
* Selecting required columns
* Filtering records
* Sorting data
* Handling duplicate or unwanted records
* Updating records where required
